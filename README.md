# Stefano Di Pierro — Video & content automation

Landing del servizio di produzione video e automazione dei flussi di lavoro per professionisti immobiliari.

Sito statico in HTML, CSS e JavaScript, senza build e senza servizi di raccolta dei contatti. I pulsanti aprono WhatsApp o una bozza email: l'invio è effettuato dal visitatore.

## GitHub Pages

Pubblicazione dal branch `main`, cartella `/`.

URL: https://stefanodipierro.github.io/video-content-automation/

## File

- `index.html`: pagina e contenuti.
- `assets/styles.css`: stile responsive.
- `assets/app.js`: confronto prima/dopo, pipeline e preparazione del brief.
- `assets/`: immagini, poster e brevi anteprime video.

Lo screenshot Metricool e i numeri del caso studio sono una documentazione storica dei lavori di novembre 2026. Gli stati programmati sono distinti da quelli pubblicati.

I materiali del portfolio non sono inclusi in una licenza open source generale.
